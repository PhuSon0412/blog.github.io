Java Collections Framework - Làm chủ cấu trúc dữ liệu

October 12, 2025 · 2 min · Phú Sơn

Java Collections Framework cung cấp các cấu trúc dữ liệu mạnh mẽ giúp quản lý nhóm đối tượng hiệu quả.

Tổng quan Collections Framework#

Collections Framework bao gồm các interface và class chính:

  • List: danh sách có thứ tự, cho phép phần tử trùng lặp
  • Set: tập hợp không có phần tử trùng lặp
  • Map: lưu trữ cặp key-value
  • Queue: hàng đợi FIFO

1. ArrayList vs LinkedList#

import java.util.*;

public class ListExample {
    public static void main(String[] args) {
        // ArrayList - truy cập nhanh theo index
        List<String> arrayList = new ArrayList<>();
        arrayList.add("Java");
        arrayList.add("Python");
        arrayList.add("JavaScript");
        
        // LinkedList - thêm/xóa nhanh
        List<String> linkedList = new LinkedList<>();
        linkedList.add("C++");
        linkedList.add("Go");
        
        // Duyệt qua list
        for (String lang : arrayList) {
            System.out.println(lang);
        }
    }
}

2. HashSet và TreeSet#

// HashSet - không thứ tự, nhanh
Set hashSet = new HashSet<>();
hashSet.add(5);
hashSet.add(2);
hashSet.add(8);
hashSet.add(2); // Không thêm được vì trùng

// TreeSet - có thứ tự tự động
Set treeSet = new TreeSet<>();
treeSet.add(5);
treeSet.add(2);
treeSet.add(8);
// Output: 2, 5, 8 (đã sắp xếp)

3. HashMap - Cấu trúc quan trọng nhất#

Map studentScores = new HashMap<>();

// Thêm dữ liệu
studentScores.put("An", 85);
studentScores.put("Bình", 92);
studentScores.put("Chi", 78);

// Lấy giá trị
int anScore = studentScores.get("An"); // 85

// Kiểm tra key tồn tại
if (studentScores.containsKey("Bình")) {
    System.out.println("Điểm của Bình: " + studentScores.get("Bình"));
}

// Duyệt qua Map
for (Map.Entry entry : studentScores.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue());
}

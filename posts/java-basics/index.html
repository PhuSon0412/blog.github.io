Những kiến thức cơ bản về Java cho người mới bắt đầu

January 10, 2024 · 1 min · Phú Sơn

Java là một trong những ngôn ngữ lập trình phổ biến nhất thế giới. Trong bài viết này, chúng ta sẽ tìm hiểu các khái niệm cơ bản của Java.

Java là gì?#

Java là ngôn ngữ lập trình hướng đối tượng, được phát triển bởi Sun Microsystems (nay thuộc Oracle). Java có đặc điểm “Write Once, Run Anywhere” - viết một lần, chạy mọi nơi.

Cài đặt Java#

Để bắt đầu với Java, bạn cần cài đặt JDK (Java Development Kit):

# Kiểm tra phiên bản Java
java -version

Chương trình Hello World đầu tiên#

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Xin chào, Thế giới!");
    }
}

Các kiểu dữ liệu cơ bản#

Java có 8 kiểu dữ liệu nguyên thủy:

  • int: số nguyên (4 bytes)
  • long: số nguyên lớn (8 bytes)
  • float: số thực (4 bytes)
  • double: số thực chính xác cao (8 bytes)
  • boolean: true/false
  • char: ký tự đơn
  • byte: số nguyên nhỏ (-128 đến 127)
  • short: số nguyên trung bình (2 bytes)
int age = 25;
double salary = 50000.50;
boolean isStudent = true;
String name = "Nguyễn Văn A";

Kết luận#

Java là ngôn ngữ mạnh mẽ và dễ học. Hãy thực hành thường xuyên để nắm vững kiến thức!
